# 자산과투자사이 (jasan-invest)

모바일·PC 개인 자산 및 투자 관리 앱의 초기 버전입니다. 현재 앱 화면 이름은 ‘자산노트’입니다.

## 기능

- 총자산·부채·순자산 대시보드와 자산 구성
- 계좌, 보유 자산, 거래, 배당·이자 관리
- 자산 추이, 부채, 목표, 현금흐름, 앱 내부 일정 관리
- 추가·수정·삭제, CSV 가져오기·내보내기, JSON 백업·복원
- 모바일·PC 반응형 화면

## 실행

별도 의존성 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 앱입니다.

```bash
git clone https://github.com/crucify87/jasan-invest.git
cd jasan-invest
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열어 사용하세요. Python이 없는 경우 다른 정적 파일 서버로 실행할 수 있습니다.

## 데이터와 초기 버전의 범위

- 처음 실행하면 가상의 샘플 데이터가 표시됩니다. ‘빈 데이터로 시작’으로 초기화할 수 있습니다.
- 실제 입력 데이터는 브라우저 localStorage에 저장됩니다. 서버 저장 및 기기 간 동기화는 지원하지 않습니다.
- 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 JSON 백업을 보관하세요.
- 거래 기록은 계좌 잔액 및 보유 수량에 자동 반영되지 않습니다.
- 시세·환율·금융계좌 자동 연동 및 푸시 알림은 미구현입니다.
- 금액은 원화 기준입니다. 해외 자산의 단가는 원화 환산값을 직접 입력하세요.
- 투자 평가손익에는 수수료·세금·배당이 포함되지 않습니다.
- 목표 진척률은 전체 순자산 기준입니다.
- CSV를 지원하며 XLSX 직접 업로드는 지원하지 않습니다.

## 파일

- `index.html`: 앱 구조
- `style.css`: 반응형 스타일
- `app.js`: 화면, 계산, 입력 및 파일 처리

공개 저장소에는 앱 소스와 가상 샘플 데이터만 포함됩니다. 개인 자산 백업, 인증정보, Sites 배포 식별자는 포함하지 않습니다.
