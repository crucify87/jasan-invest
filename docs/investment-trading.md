# 투자 현황 · 매매 원장 · 시세 연결

## 사용 순서
1. 기존 앱에서 JSON 백업을 내려받습니다.
2. 계좌 현금 잔액과 종목별 현재 보유 수량·평균 매입가를 맞춥니다. 신규 관심 종목은 수량 0으로 등록할 수 있습니다.
3. 투자 현황의 종목 카드에서 목표 수익률(기본 15%, 직접 수정), 매수 검토가(0은 미설정)를 설정합니다. 손절 기준은 평균 매입가 대비 -10%로 고정합니다.
4. 매수 기록/매도 기록에서 수량·원화 환산 체결 단가·수수료·세금·거래일을 입력합니다. 계좌 현금은 자동 반영되므로 같은 거래에 대해 별도로 출금·입금 기록을 더해 중복 계산하지 않습니다.
5. 현재가를 직접 입력하거나 서버 시세를 연결하면 평가액·수익률·기준 도달 상태가 다시 계산됩니다. 이것은 사용자 설정 기준에 대한 검토 알림이며 실제 주문을 실행하지 않습니다.

## 계산과 기존 기록
- 최초 연결 거래 시 기존 보유 수량/평균 매입가와 계좌 잔액을 기초 값으로 보관합니다. 기초 값은 첫 거래 직전의 상태여야 합니다.
- 기존 기록용 거래는 자동 반영하지 않습니다. 이미 보유 수량·현금에 반영한 과거 거래를 새 연결 거래로 다시 등록하지 마세요.
- 매수 평균 단가 = (기존 잔여 취득원가 + 매수금액 + 수수료 + 세금) / 매수 후 수량.
- 매도 실현손익 = 매도금액 - 수수료 - 세금 - (당시 평균 단가 × 매도 수량). 매도 후 남은 수량의 평균 단가는 유지합니다.
- 원화 이동평균 방식이며 세금은 입력한 값입니다. 세무 신고용 법정 손익 계산 기능은 아닙니다.
- 거래는 날짜순, 같은 날짜는 최초 등록 순서로 재계산합니다. 수정/삭제 시 전체 연결 거래를 재생합니다. 당시 보유 수량 초과·현금 부족·기초 기준일 이전·미래 거래는 거부합니다.
- 연결 거래가 있는 자산의 수량·평균 단가·계좌는 직접 바꾸지 않고 거래로 관리합니다. 계좌 현금을 수정하면 기초 현금에도 차이를 반영해 이후 거래를 재계산합니다.
- 거래가 연결된 자산은 먼저 거래를 정리해야 삭제할 수 있습니다. 백업에는 기초 값·연결 거래·목표·시세 이력이 포함됩니다.
- 기존 CSV 형식은 계속 기록용입니다. 연결 거래의 완전한 보관·복원에는 JSON 백업을 사용하세요.
- 가격 흐름은 앱이 저장한 최근 120개 시세와 매수·매도 지점을 표시합니다. 과거 전체 시장 차트가 아닙니다.
- 손절은 고정 취득원가 대비 -10%이며 최고가 대비 추적 손절이 아닙니다. 목표 수익률 자체를 시장에 맞춰 자동 변경하지 않습니다.
- 소수 수량을 지원하며 표시 금액만 원 단위 반올림합니다. 계산은 자바스크립트 부동소수점이므로 실제 금융기관 원장과 미세한 차이가 날 수 있습니다.
- 분할·합병·배당·환전·계좌 이체·증권사 거래 자동 수집은 이번 연결 원장 범위에 포함되지 않습니다.

## Cloudflare 서버 시세 설정
기존 정적 Workers 배포에 \`workers/quotes.js\`를 추가했습니다. 루트의 \`wrangler.jsonc\`에 main, ASSETS binding, /api/* 우선 라우팅이 포함됩니다. 기존 배포 명령 \`npx wrangler@4 deploy\`를 사용합니다. Firebase 보안 규칙의 최상위 데이터 구조는 변경하지 않습니다.

Twelve Data의 종목별 조회 권한·지연 여부·환율 지원·공개/회원제 서비스에서의 표시 및 재배포 조건을 먼저 확인합니다. 지원 시장과 상품은 가입 요금제에 따라 달라집니다. 특정 국내 종목의 지원을 보장하지 않습니다. 계정·유료 서비스를 자동 생성하거나 결제하지 않습니다.

Cloudflare → Workers & Pages → jasan-invest → Settings → Variables and Secrets:
- \`TWELVE_DATA_API_KEY\`: **Secret**으로 저장. GitHub·프런트엔드·채팅에 넣지 않습니다.
- \`QUOTE_INSTRUMENTS\`: 조회를 허용할 종목·거래소의 JSON 배열. 예시(실제 사용할 종목으로 교체):
  \`[{"symbol":"AAPL","exchange":"NASDAQ"}]\`
- 저장 후 재배포합니다. 자산 수정에서 위 값과 같은 종목 코드/거래소를 입력합니다.

앱의 연결 시세 갱신 버튼은 GET /api/quotes를 호출합니다. 공급자 키 미설정은 503, 미허용 종목은 400으로 명확히 실패하며 가격을 임의로 바꾸지 않습니다. 키는 서버에서만 사용합니다. 서버 허용 목록만 조회하며 성공 응답은 60초 캐시합니다. 이 API는 공개 시장가격만 반환하고 회원·자산 데이터를 반환하지 않습니다. 공개 API이므로 운영자는 Cloudflare의 호출 제한/비용 모니터링을 서비스 규모에 맞춰 설정해야 합니다.

공급자의 /quote 응답에서 종목·거래소·양수 가격·통화·원본 타임스탬프를 검사합니다. KRW 외 USD/EUR/JPY/GBP/HKD/CAD/AUD/CHF는 /exchange_rate를 통해 KRW로 환산하고 환율 기준 시각도 표시합니다. API 플랜에서 환율 조회가 허용되어야 합니다. 지원되지 않는 통화, 오래된 저장 시세를 덮는 응답, 실패·잘못된 응답은 적용하지 않습니다.

사용자가 자동 갱신을 켠 경우에만 앱이 보이는 투자 현황 화면에서 5분마다 갱신합니다. 로그아웃/세션 잠금 시 중지하며 백그라운드 알림·실시간 스트리밍은 아닙니다. 휴장 시 과거 종가가 올 수 있으므로 시세 기준 시각을 표시하고 24시간이 넘으면 최신 가격 확인 안내를 표시합니다.

## 확인 범위
- 순수 계산/화면/Worker 모의 응답 테스트, 문법/경로 검사, 정적 빌드를 실행합니다.
- 실제 공급자 API 키·조회 권한·운영 계정 로그인·Cloudflare 실배포 검증은 별도로 필요합니다.
- 상태는 한 회원의 Firestore 문서에 저장됩니다. 다중 기기 동시 편집 충돌 처리와 문서 용량 확장은 별도 작업입니다.
