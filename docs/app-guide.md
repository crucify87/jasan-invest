# 사용 안내

이메일·Google·전화번호로 인증한 뒤 이름 또는 닉네임과 개인정보 동의 항목을 작성해 가입을 신청합니다. 관리자가 승인하기 전에는 자산 관리 기능을 사용할 수 없습니다. 이메일 가입은 이메일 인증이 필요합니다.

로그인한 회원별로 자산 자료를 서버에 저장합니다. 신규 회원은 빈 데이터로 시작합니다. 기존 앱의 JSON 백업은 자료 가져오기 화면에서 복원합니다.

관리자는 2단계 인증 후 회원 승인·거절·정지와 처리 이력을 관리합니다. 다른 회원 자산은 앱에서 조회할 수 없습니다.

거래 기록은 보유 수량과 계좌 잔액에 자동 반영되지 않습니다. 가격과 환율은 직접 입력합니다.
